# SoussVoice Native-Speaker Benchmark

Primary variety: Agadir/Souss Tachelhit
Primary script: Latin
Secondary script: Tifinagh

Purpose:
Evaluate comprehension, response quality, naturalness,
dialect accuracy, and spelling variation.

Rules:
1. Evaluation examples must not be used for training.
2. Native-speaker-approved answers are the reference.
3. Multiple natural expressions may be accepted.
4. Translation and conversation are scored separately.
5. Keep original recordings and transcriptions.
